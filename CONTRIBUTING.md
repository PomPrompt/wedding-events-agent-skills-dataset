# Contributing and reporting corrections

Contributions are welcome as **links and evidence**, not uploads or copies of external Skill assets.

1. Search existing core records, pending leads and duplicate mapping before proposing a new Skill.
2. Include the individual public Skill URL, observed page title, source page URL, suggested primary category and public evidence of wedding relevance.
3. Label A when explicitly wedding-specific, B only when the public description explicitly names weddings, or C when applicability is unconfirmed.
4. Note if the link is inaccessible or if it might be a duplicate of another specific entry.
5. Do not include third-party SKILL.md texts, scraped scripts, confidential data, user identities or personal guest information.
6. Dataset maintainers should recheck the specific page, record actual research date, review identity, update JSON and CSV together, and run `scripts/validate_dataset.py` before committing.

This repository is a discovery directory and does not assess software safety, licenses, compatibility or execution.
